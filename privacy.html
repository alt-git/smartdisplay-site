プライバシーポリシー

最終更新日: 2026年10月20日

本ポリシーは、個人利用のデスクトップアプリケーション「SmartDisplay」（以下「本アプリ」）における 利用者情報の取り扱いについて定めるものです。本アプリは開発者本人のみが利用する目的で作成されており、一般には配布していません。

1. 取得する情報

本アプリは、利用者が Google アカウントでログインし許可した場合に限り、以下の情報を取得します。

  • Google カレンダーの予定（タイトル、開始・終了日時、場所、説明）

取得には Google Calendar API の読み取り専用スコープ https://www.googleapis.com/auth/calendar.readonly のみを使用します。

2. 利用目的

取得した情報は、本アプリの画面に予定を表示する目的にのみ使用します。

3. 保存

  • 取得した予定は、通信できない場合にも表示するため、本アプリを実行している端末内にのみ一時的に保存します。
  • ログイン状態を維持するための認証情報は、Windows の暗号化機能（DPAPI）で暗号化し、端末内にのみ保存します。
  • これらの情報を開発者のサーバーや外部のサービスへ送信することはありません。

4. 第三者への提供

取得した情報を第三者に提供、販売、共有することはありません。広告や分析の目的にも使用しません。

5. Google API サービスのユーザーデータに関するポリシーの遵守

本アプリによる Google API から取得した情報の使用および他のアプリへの転送は、 Google API サービスのユーザーデータに関するポリシー （限定的使用の要件を含む）を遵守します。

6. アクセスの取り消しとデータの削除

  • Google アカウントの サードパーティ製のアプリとサービス から「SmartDisplay」のアクセスをいつでも取り消すことができます。
  • 端末内に保存されたデータは、本アプリのデータフォルダーを削除することで消去できます。

7. お問い合わせ

本ポリシーに関するお問い合わせは、本ページを公開している GitHub リポジトリの Issues からご連絡ください。

8. 改定

本ポリシーは必要に応じて改定することがあります。改定後の内容は本ページに掲載した時点で有効となります。
